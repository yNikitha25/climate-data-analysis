# Climate Analysis Project 🌍📊

A Climate Data Analysis project built using Python and Jupyter Notebook to analyze climate patterns, trends, and environmental changes using real-world datasets.

---

## 🚀 Features

- Data Cleaning & Preprocessing
- Climate Trend Analysis
- Data Visualization
- Statistical Insights
- Correlation Analysis

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Project Files

- `climate_analysis.ipynb` → Main analysis notebook
- `climate data.csv` → Climate dataset
